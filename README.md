# IfG SlideStyler | PowerPoint Vorlagen-Engine

Internes Tool zur 1:1 Konvertierung von PowerPoint-Präsentationen in das offizielle Corporate Design des Instituts für Gesundheit und Management (IfG) / Arsipa.

## Features
- **100% 1:1 Layout-Erhaltung**: Alle Grafiken, Formen, Gruppen, Tabellen, Bilder und SmartArt-Diagramme bleiben exakt in ihrer ursprünglichen Struktur und Position erhalten.
- **Offizielle Typografie**: Abadi
- **Offizielle Unternehmensfarben**: Deep Navy (`#012641`), Corporate Teal (`#00A8B7` / `#3EB9C0`), Slate Charcoal (`#3A4A63`).
- **Kompatibilität**: 100% editierbar und fehlerfrei unter Windows 11 & SharePoint Online.
